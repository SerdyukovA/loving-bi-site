Как довести до ума

  1. Открой Claude Code в папке репозитория и скажи: «прочитай скилл dataviz-dashboards и задай мне 10 вопросов, где правило звучит не так, как сказала бы я».
  2. Дай реальную задачу без данных: «нужен дашборд по возвратам для категорийных менеджеров». Правильные ли вопросы он задаёт?
  3. Всё, что не так, говори прямо: «здесь неверно, я делаю так-то». Он сам поправит файлы.
  4. Сохранить: «подними версию, допиши CHANGELOG, закоммить и запушь». Через минуту новая версия в GitHub, а у тебя в Claude скилл обновится при следующем запуске.

Как он обновляется сам работает

  1. Выходит новый пост → робот раз в сутки сравнивает его со скиллом.
  2. Если в посте новое правило или оно противоречит старому — робот готовит правку (pull request) и присылает ссылку в бот.
  3. Ты открываешь правку в GitHub: видно, что именно меняется и из какого поста. Merge — принять, Close — отклонить, комментарий — попросить переделать.
  4. Принятая правка = новая версия скилла: номер версии, строка в CHANGELOG.md и в sources.md уже внутри правки.
  5. Если висят две правки сразу, принимай по одной: вторая может споткнуться о номер версии. GitHub напишет «conflicts» — напиши Алексею.

Если что-то сломалось

  • Пост не появился на сайте через сутки — загляни в Actions. Красный прогон → открой Claude Code в репозитории и скажи «посмотри последний упавший прогон scrape.yml и почини».
  • Нужно прямо сейчас, не ждать суток: Actions → Scrape Telegram → Run workflow.
  • Сайт открывается, но что-то сломано после твоей правки — в GitHub откати последний коммит или попроси Claude «откати мой последний коммит».
  • Не разобралась — пиши Лёше.
