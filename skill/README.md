# Скилл «Дашборды и датавиз» — для Леры

Это инструкция для Claude, собранная из твоих постов в @loving_bi. Когда ты просишь Claude
«спроектируй дашборд» или «прожарь мой дашборд», он открывает этот скилл и работает по твоим
правилам: сначала задаёт вопросы заказчику, потом выбирает тип дашборда, раскладку, графики и цвета.

## Что внутри

- `dataviz-dashboards/SKILL.md` — главный файл: порядок работы и формат ответа.
- `dataviz-dashboards/references/` — подробности по темам: вопросы до дашборда, макеты, выбор графика, цвет, гештальт, честность, UX, A/B, карты, чек-лист прожарки.
- `dataviz-dashboards/sources.md` — из какого поста взято каждое правило.
- `dataviz-dashboards/CHANGELOG.md` — версии.

## Как довести до ума (первые итерации)

1. Открой Claude Code в папке с этим репо и скажи: «прочитай скилл dataviz-dashboards и задай мне 10 вопросов, где правило звучит не так, как я бы сказала».
2. Дай ему реальную задачу с работы без данных: «нужен дашборд по возвратам для категорийных менеджеров». Посмотри, правильные ли вопросы он задаёт.
3. Всё, что не так, говори прямо: «здесь неверно, я делаю так-то». Пусть сам правит файлы.
4. Сохранить версию: «обнови CHANGELOG и закоммить».

## Как он будет обновляться сам

Новый пост в канале → робот раз в сутки читает пост и сравнивает со скиллом → если есть
новое правило или поправка, присылает тебе в Telegram ссылку на предложение (pull request) →
ты жмёшь Merge (принять) или Close (отклонить). Принятое попадает в новую версию.
