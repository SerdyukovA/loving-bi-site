# Оформление результатов A/B-тестов (56)

Подача, не статистика. Цель: прозрачно, понятно, без искажений.

Дашборд под A/B — исследовательский тип (см. `layouts.md`): всё подписано, тултипов нет.

## 5 правил (239)
1. **Тестовая группа — цветом, контрольная — нейтральной (серой).** Не две равноправные цветные линии.
2. **Дата старта теста — на графике**: вертикальный пунктир с подписью «начало теста», чтобы было видно, где начинается влияние изменений.
3. **Не обрезать ось в барчартах**: ось от 0, а не 85–95, иначе маленькая разница выглядит пропастью (см. `honesty.md`).
4. **Форматировать данные**: изменение метрики (Δ) подсвечивать цветом, рост «хорошей» метрики зелёным, падение красным (см. `color.md`).
5. **Сначала ключевые метрики, дополнительные — отдельно**: сверху главная метрика с Δ (заказы +15%), остальные (выручка, клики) убрать в раскрывающийся блок «доп. метрики», а не давать одним списком на равных.
