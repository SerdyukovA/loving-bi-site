# UX дашборда: чек-лист

Принцип: секунды, которые пользователь тратит на поиск, скролл и счёт в уме, повторяются
много раз в день у многих людей. Фикс почти всегда дешевле этих потерь (45).

## Раскладка и навигация
- [ ] Самые используемые фильтры — в начале и рядом друг с другом (обычно дата + главные разрезы); близкие по смыслу фильтры — в своих блоках (45)
- [ ] Фильтр, который относится к одному графику, — рядом с этим графиком или внутри него (155)
- [ ] Много фильтров (операционный дашборд) → группировать в контейнеры по подтемам: «признаки товара», «признаки обращения» (159)
- [ ] Таблица для выгрузки — на отдельной вкладке, не в самом низу (45, 223)
- [ ] Нет горизонтального скролла в графиках и таблицах; вместо него — масштаб, меньше колонок, спарклайны вместо «таблицы с динамикой» (80)
- [ ] Графики не растянуты на весь экран: хуже виден тренд, свежие значения упираются в правый край (80)

## Тексты
- [ ] Заметка о графике — рядом с графиком, не на отдельной вкладке (45)
- [ ] Заголовки и заметки понятны маме (45)
- [ ] Нет огромных описаний; если текста много — структура, буллеты, выделение главного. Если дашборд требует много объяснений, возможно, он слишком сложный (80)
- [ ] Эмодзи только со смыслом (🎤 микрофон, 🎥 камера в названиях колонок; 🇷🇺/🇬🇧 у двуязычного readme), не «для красоты» (80)
- [ ] Есть контакт или ссылка для вопросов по дашборду (80)

## «Пусть потеет машина» (183)
- [ ] Тултип даёт контекст: отклонение от плана, WoW, сопутствующие показатели
- [ ] При недельной сезонности в тултипе — день недели
- [ ] Даты по умолчанию относительные (Last 90 days, Last month), а не фиксированные
- [ ] Фильтры по умолчанию = то, что пользователи чаще всего выставляют руками (логи или спросить)
- [ ] Если пользователь складывает разрезы в уме — показывать тотал по умолчанию, разрез сделать опцией (45)

## Разрезы (split by) (212)
- [ ] Вместо десятка одинаковых графиков — один график с параметром split by (в SQL — case по значению параметра)
- [ ] На графике несколько метрик → split by только по главной (вспомогательную скрыть) или подграфики на каждую метрику
- [ ] Самый популярный split by по логам — готовым графиком на дашборде

## Чего избегать
- [ ] Анимации (их ждут) и сложные/редкие типы графиков (в них разбираются). Ценность дашборда — скорость считывания (45, 134)
- [ ] «Интересненьких» нестандартных элементов управления: стандартные паттерны выигрывают (пример: радиокнопки вместо нестандартного выбора тарифа дали +20% конверсии, 136)
