# Данные на картах (74)

Карта нужна, только когда география — часть ответа. Иначе — барчарт или топ-списки.

1. **Числа — градиент светлый → тёмный** по смыслу данных. Не радуга бинов, не градиент со светлым центром.
2. **Категории — равнозначные ассоциативные цвета** (мёд жёлтый, молоко светло-серое, мясо красное, овощи зелёные, рыба голубая), не оттенки одного цвета. В легенде — иконки.
3. **Количество — кругами (пузырями) на сером фоне**, не заливкой: заливка «награждает» вниманием большие по площади регионы с маленькими значениями.
4. **Подписывать только нужное**: регионы для контекста или для акцента. Подписи всех регионов — каша.
5. **Дополнять другими графиками**. Если зависимости от географии нет — рядом топ-5 наибольших и топ-5 наименьших регионов со значениями.
